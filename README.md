# 🚀 Nombre del Proyecto

Una red social construida por pasatiempo/ocio.

## 📌 Estado del Proyecto
> 🚧 **En construcción / En fase inicial (0%)**

Este proyecto es un experimento personal para aprender, practicar y construir una plataforma de red social desde cero.

---

## 🎯 Objetivos y Características Planificadas

- [ ] Registro e inicio de sesión de usuarios (Autenticación)
- [ ] Perfiles de usuario personalizables
- [ ] Creación y publicación de posts (texto, imágenes)
- [ ] Feed interactivo (publicaciones de otros usuarios)
- [ ] Sistema de interacción (me gusta, comentarios, compartir)
- [ ] Sistema de seguimiento (seguir/dejar de seguir usuarios)
